## 产品名称

Enhanced Snap

## 简短描述

增强版的 Windows 贴靠：同样的贴靠手势、布局和贴靠组，再加上圆角与均匀间距。

## 描述

Enhanced Snap 在 Windows 11 上取代 Windows 贴靠。你熟悉的操作全都一样——把窗口拖到边缘或角落、把指针停在最大化按钮上、
按 Win + Z、在贴靠助手中挑选窗口——而贴靠后的窗口会保留圆角，彼此之间还有统一的 Fluent 间距。

Enhanced Snap 运行时会关闭 Windows 贴靠并由自己接管；暂停、退出或卸载后，Windows 贴靠就会恢复。

WINDOWS 贴靠能做的，它都能做
• 把窗口拖到侧边、角落或顶部；放到屏幕顶部的贴靠栏
• 最大化按钮与 Win + Z 的贴靠布局，并根据最近使用的应用提供贴靠建议
• 显示实时缩略图的贴靠助手，可用鼠标或键盘操作
• 任务栏预览、Alt + Tab 和任务视图中的贴靠组
• 组内窗口之间的分隔条；Win + 方向键可在区域和显示器之间移动

它还多了这些
• 贴靠后的窗口保留圆角，并按各显示器缩放的均匀间距排列
• 每个组后方的底板，可选云母、云母 Alt、亚克力或纯色，并跟随浅色与深色模式
• 把任意窗口拖到组的空位上即可补满
• 在组上点 X 会关闭其中所有窗口；在组中按 Alt + Tab 时组排在第一个
• 分隔条会停在每个应用的最小尺寸，任何窗口都不会被挤压
• 每个显示器 11 种布局，也可自定义列和行；按 Shift 显示区域，按 Ctrl 跨越区域
• 省电：空闲时没有计时器、以效率模式运行、节能模式下改用纯色

提供 English、繁體中文和简体中文。无需账户、没有广告、没有遥测：数据不会离开你的电脑。

Enhanced Snap 是独立应用，与 Microsoft 无关。

## 产品功能

1. 运行时取代 Windows 贴靠，暂停、关闭或卸载后即恢复
2. 贴靠后的窗口保留圆角
3. 窗口之间与屏幕边缘的均匀间距，按各显示器缩放
4. 最大化按钮与 Win + Z 的贴靠布局，并提供贴靠建议
5. 显示实时缩略图的贴靠助手
6. 任务栏预览、Alt + Tab 和任务视图中的贴靠组
7. 组底板：云母、云母 Alt、亚克力或纯色
8. 把窗口拖进组的空位
9. 用分隔条一起调整组内窗口的大小
10. 每个显示器 11 种布局，并可自定义列和行
11. Win + 方向键在区域和显示器之间移动
12. 浅色与深色模式；English、繁體中文、简体中文
