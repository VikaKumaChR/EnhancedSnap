## 產品名稱

Enhanced Snap

## 簡短描述

升級版的 Windows 貼齊：相同的貼齊手勢、版面配置與貼齊群組，再加上圓角與等距間隔。

## 描述

Enhanced Snap 在 Windows 11 上取代 Windows 貼齊。您熟悉的操作全都一樣——把視窗拖到邊緣或角落、把指標停在最大化按鈕上、
按 Win + Z、在貼齊輔助中挑選視窗——而貼齊後的視窗會保留圓角，彼此之間還有一致的 Fluent 間距。

Enhanced Snap 執行時會關閉 Windows 貼齊並由自己接手；暫停、結束或解除安裝後，Windows 貼齊就會恢復。

WINDOWS 貼齊能做的，它都能做
• 把視窗拖到側邊、角落或頂端；放到畫面頂端的貼齊列
• 最大化按鈕與 Win + Z 的貼齊版面配置，並依最近使用的應用程式提供貼齊建議
• 顯示即時縮圖的貼齊輔助，可用滑鼠或鍵盤操作
• 工作列預覽、Alt + Tab 與工作檢視中的貼齊群組
• 群組視窗之間的分隔線；Win + 方向鍵可在區域與顯示器之間移動

它還多了這些
• 貼齊後的視窗保留圓角，並依各顯示器縮放一致的間距
• 每個群組後方的底板，可選雲母、雲母 Alt、壓克力或純色，並跟隨淺色與深色模式
• 把任何視窗拖到群組的空位上即可補滿
• 在群組上按 X 會關閉其中所有視窗；在群組中按 Alt + Tab 時群組排在第一個
• 分隔線會停在每個應用程式的最小尺寸，任何視窗都不會被擠壓
• 每個顯示器 11 種版面配置，也可自訂欄與列；按 Shift 顯示區域，按 Ctrl 跨越區域
• 省電：閒置時沒有計時器、以效率模式執行、節能模式下改用純色

提供 English、繁體中文與简体中文。不需帳戶、沒有廣告、沒有遙測：資料不會離開您的電腦。

Enhanced Snap 為獨立應用程式，與 Microsoft 無關。
